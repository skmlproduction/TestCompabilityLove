## Конфликт

| Слой | Что заявлено |
|------|--------------|
| SKU в коде и Console | `remove_ads` |
| Реклама в сборке | **Выключена** (`lovetest.ads.enabled=false`), AD_ID и автозапуск AdMob удалены из release |
| Paywall в приложении | «Поддержка разработчиков», добровольный tip — все тесты бесплатны |
| Листинг (RU/EN) | Premium «убирает рекламу в будущих версиях» |

Покупатель платит за «remove ads», рекламы нет. Ценность покупки = благодарность. Для Google Play это допустимо (donation/tip-jar IAP — распространённая практика), но формулировки должны быть честными везде.

## Вариант A — честный tip-jar (рекомендую)

Оставить рекламу выключенной, привести названия к честному виду.

- Console: название товара `remove_ads` (ID не меняется!) → отображаемое имя **«Premium — поддержка разработчиков» / «Premium — support the developers»**.
- Листинг: заменить «убирает рекламу в будущих версиях» → «разовая поддержка разработчиков; все тесты всегда бесплатны».
- Код не трогаем: paywall уже честный.
- Плюсы: нулевая работа с кодом, никакого риска ревью, нет рекламной нагрузки на пользователей, Data safety не меняется.
- Минусы: конверсия tip-jar низкая (~0.1–0.5%).

## Вариант B — настоящий remove_ads

Включить рекламу для free-пользователей, Premium = отключение рекламы.

- Нужно: `lovetest.ads.enabled=true` + реальные AdMob ID (сейчас тестовые/пустые), удалить `app/src/release/AndroidManifest.xml`, перепройти **Data safety** (Ads: Yes, Advertising ID) и **IARC** (Contains ads: Yes), consent UMP для ЕС, пересборка + полный QA.
- Плюсы: реальный рекламный доход + понятная ценность Premium.
- Минусы: 1–2 недели работы, новый ревью-риск, ухудшение UX, ожидание одобрения AdMob-аккаунта.

## Вариант C — гибрид (отложенный)

v1 выходит по варианту A; реклама включается в v1.2+ после накопления аудитории. Тогда же меняются формы. Это и есть заложенный в документах путь («При v1.2 + ads — пересдать Data safety + IARC»).

**A сейчас, B/C позже.** Релиз не должен ждать монетизационную стратегию: tip-jar честен, безопасен для ревью и уже реализован. После решения я внесу правки в листинг/Console-тексты за одну сессию.
